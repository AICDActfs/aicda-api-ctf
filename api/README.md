# AICDA API CTF - Vulnerable Backend

This is an intentionally vulnerable Flask API built for CTF educational purposes.

## Deployment on Fly.io

1. Install `flyctl` and authenticate.
2. Run `fly launch` in this directory (use existing config).
3. Run `fly deploy` to deploy the application.

## Vulnerabilities
This API contains various vulnerabilities ranging from JWT attacks, IDOR/BOLA, Mass Assignment, SQL Injection, and more.
